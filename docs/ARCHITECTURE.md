# Архитектура PNEUMA Full v0.4

```
Sensors (физика + физиология)
    ↓
Analytics (паттерны, risk, recovery)
    ↓
Reflection (observation / interpretation / hypothesis)
    ↓
Intuition (генерация проверяемых гипотез)
    ↓
Ethics (мудрость / воля / любовь + трактат)
    ↓
Archetypal Layer (опционально, hypothesis_not_fact)
    ↓
Safety Gate (human-in-the-loop + audit)
    ↓
Reporting (JSON + Markdown)
```

Все архетипические и «одухотворённые» выводы несут явный эпистемический статус.
